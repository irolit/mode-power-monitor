# MODE Power Monitor — этап P0 (проверка доступа)

**Цель:** выяснить, открывается ли официальная страница графиков ДТЭК КРЕМ (https://www.dtek-krem.com.ua/ua/shutdowns) из инфраструктуры GitHub. Этот набор ничего не обходит: обычный браузер, настройки по умолчанию, 3 запроса с паузой в минуту, без входа и без вашего адреса. Если сайт покажет страницу-защиту, мы это зафиксируем и **остановимся**.

Правила сайта могут ограничивать автоматический доступ. Это ваше решение; P0 делает минимум запросов (3 за запуск).

## Что сделать (≈10 минут, бесплатно)
1. Зарегистрируйтесь на github.com (если нет аккаунта) → **New repository** → название `mode-power-monitor`, **Public**, без README.
2. Загрузите в репозиторий содержимое этой папки (кнопка *Add file → Upload files*, перетащите папки `.github` и `probe` и файл `README.md`). Папка `.github` скрытая: если Windows её не показывает, включите «Скрытые элементы» в Проводнике. Нажмите *Commit changes*.
3. Вкладка **Actions** → если просит, нажмите *I understand my workflows, enable them*.
4. Слева выберите **P0 probe** → *Run workflow* → *Run workflow*.
5. Через 3–4 минуты откройте этот запуск → внизу страницы **Summary** покажет таблицу «DTEK probe». Пришлите мне скриншот таблицы (и, если есть, артефакт `probe-result`).
6. Workflow дополнительно сам запускается раз в 3 часа. Дайте ему поработать сутки, чтобы получить картину в разное время, и пришлите мне итог (сколько запусков OK / PARTIAL / NOT_AVAILABLE).
7. После P0 уберите блок `schedule:` из `p0-probe.yml` (или удалите репозиторий), если мониторинг дальше строить не будем.

## Как читать результат
- `schedule_data_present` — страница открылась и содержит скрипт с графиком: GitHub **может** получать данные.
- `protection_challenge` / `blocked_with_protection_page` — сайт показал проверку или блокировку: **строить мониторинг на GitHub нельзя**. Я не буду пытаться обойти. Запасной план: чтение через ваш Brave на ноутбуке.
- `blocked_http_NNN`, `empty_or_tiny_page`, `unknown_page` — нужна дополнительная диагностика (пришлите скриншот).

## Что проверено
Автотестами (`npm test`, 5 тестов на заглушках): только распознавание типов страниц. **Реальный доступ из GitHub не проверялся**: это и есть цель P0, результат будет только после вашего запуска.
